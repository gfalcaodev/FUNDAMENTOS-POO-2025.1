# 👨‍💻 FUNDAMENTOS-POO-2025.1

Este repositório reúne todas as atividades resolvidas ao longo da disciplina de **Fundamentos de Programação Orientada a Objetos**, parte integrante do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da **PUC Goiás**. Os códigos foram desenvolvidos utilizando a linguagem **Java**, com foco na aplicação prática dos conceitos fundamentais de POO.

---

## 📚 Visão Geral

A disciplina tem como objetivo introduzir os pilares da Programação Orientada a Objetos, incluindo:

- Criação de classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Modularização com métodos
- Manipulação de arquivos
- Desenvolvimento incremental de sistemas

Este repositório também visa servir como fonte de consulta e inspiração para outros estudantes.

---

## 🧠 Conteúdos Abordados

- ✅ Variáveis e Tipos de Dados  
- ➕ Operadores Lógicos e Aritméticos  
- 🔁 Estruturas Condicionais (`if`, `else`, `switch`)  
- 🔂 Laços de Repetição (`for`, `while`, `do-while`)  
- 📊 Vetores e Matrizes  
- 🧩 Modularização com Métodos  
- 🧱 Orientação a Objetos (POO)  
- 📦 Projeto Final com múltiplas classes  
- 🗃️ Manipulação de Arquivos
