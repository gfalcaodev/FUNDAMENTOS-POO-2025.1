# 🚗 Exercício: Cálculo de Tarifas de Estacionamento

Este exercício simula o cálculo de tarifas de um estacionamento, baseado em tempo de permanência e regras específicas.

---

## 📝 Enunciado

Um estacionamento cobra:

- 💵 **Tarifa mínima:** R$ 5,00 para até 3 horas.
- ⏱️ **Tarifa adicional:** R$ 1,00 para cada hora (ou fração) após as 3 primeiras.
- 🚫 **Tarifa máxima:** R$ 30,00 por período de 24h.

⚠️ Nenhum carro permanece mais de 24h.

---

## 🎯 Objetivo

Desenvolver um aplicativo em **Java** que:

1. Receba a hora de entrada e de saída de **cada cliente**.
2. Calcule a tarifa com base nas regras acima.
3. Mostre:
   - 💳 Valor cobrado de cada cliente.
   - 📊 Valor total arrecadado no dia.

---

## 📚 Aprendizados envolvidos

- Operações com números decimais
- Estruturas de controle (`if`, `while`, etc.)
- Funções
- Arredondamento com `Math.ceil`
- Organização de código para múltiplos clientes
